# Python Todo App 📝

A simple command-line Todo application built with Python.

This project allows users to log in and manage their daily tasks.

## Features

- User Login
- Add Tasks
- View Tasks
- Delete Tasks
- Exit Application

## Technologies Used

- Python 
- Lists
- Loops
- Match Case
- User Input

## How to Run

1. Download the project
2. Open the project folder
3. Run the Python file:
   python Todo_app.py
